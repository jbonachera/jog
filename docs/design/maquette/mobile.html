Le tableau de bord dans la poche

Même produit, mêmes calculs et mêmes données d'exemple que la maquette bureau, recomposés pour une lecture rapide le matin, au pouce.

  • Le verre Liquid Glass est réservé à la navigation : barre d'onglets, boutons, feuilles, menus. Le contenu reste en surfaces Fjord pleines.
  • La barre d'onglets se réduit quand on défile vers le bas, pour laisser la place au contenu.
  • Les signaux, les semaines du journal et le simulateur s'ouvrent dans des feuilles.
  • Sur les graphiques, on glisse le doigt pour lire les valeurs : la lecture s'affiche au-dessus du graphique, sous le doigt rien n'est masqué.
  • Les Paramètres passent dans le bouton en haut à droite, comme dans les apps Apple.

Ouvrez ce fichier sur un iPhone pour le voir en plein écran. Toutes les valeurs sont des données d'exemple.

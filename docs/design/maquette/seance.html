Même grammaire pour les quatre types : surtitre et verdict, chiffre héros, phrase, tracé coloré par l'allure, puis les blocs propres au type (jauges D-025 et graphes). Le chiffre héros change selon le type : distance pour le footing et la sortie longue, structure pour le sous-seuil, temps pour la course.
